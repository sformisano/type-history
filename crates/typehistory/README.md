# Typehistory crates

These crates implement declarative histories for Rust record types. The
[repository README](../../README.md) starts with a complete Receipt tutorial and
continues with field rules, lifecycle commands, decoding, and supported types.

The [guide](docs/guide.md) explains the changes in the Receipt and Invoice examples
and what their tests establish. The [executable example](examples/invoice/README.md)
contains the commands for running those checks.

The [evolution matrix](docs/evolution-matrix.md) records supported and rejected
combinations for readers checking a specific declaration rule.
